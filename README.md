# Password Strength Checker (`pw_final.py`)

A simple yet effective Python script developed as part of a cybersecurity initiative to help employees assess their password security and adopt stronger authentication habits.

## 🚀 Features

* **Length Verification:** Ensures passwords meet minimum security length requirements (typically 8+ characters).
* **Case Sensitivity Check:** Verifies the inclusion of both uppercase and lowercase letters.
* **Complexity Enforcement:** Checks for the presence of numeric digits (`0-9`) and special characters/symbols (e.g., `!@#$%^&*`).
* **Actionable Feedback:** Provides specific recommendations on how weak passwords can be improved to mitigate unauthorized access risks.
